# Offline reading

Keep Amazon plus KOReader; no custom home app or framework termination is needed for this baseline.

## Books

Use a separate reading folder, for example documents/Reading/English. Keep originals and sidecars in place. Identify language from metadata and text, not title alone. Never bulk move/delete by language.

KOReader does not directly read KFX. Convert only authorized unprotected copies on the PC using a reviewed tool, then validate output. Changing an extension is not conversion. No converter or DRM-removal tool is distributed here.

Amazon and KOReader maintain separate positions/notes. OPDS downloads files; it does not migrate progress. No automatic synchronization is promised.

## Dictionaries

For B1+ English, start with simple English, English–Spanish support and a larger English fallback. KOReader uses compatible StarDict data in its dictionary directory. Check [official support](https://github.com/koreader/koreader/wiki/Dictionary-support), [Wiktionary StarDict](https://github.com/xxyzz/wiktionary_stardict) and [WikDict](https://www.wikdict.com/page/about).

Verify license, date, language direction and file/index integrity, retaining attribution. No datasets are redistributed here. Long-press a real word and check the popup/order plus vocabulary/context; command-line lookup alone does not prove UI behavior.

Amazon uses its own compatible dictionaries. The StarDict files do not automatically work there. Select/download native dictionaries through supported account options where available, without unauthorized purchase or copying.

## Minimal useful features

Use built-in vocabulary, layout controls and [local highlight exports](https://github.com/koreader/koreader/wiki/Highlight-export) before external plugins. Exported Markdown is a copy; keep personal notes separate from re-exported files.

Test covers in each reader separately: [procedure](COVERS.md). Before a trip, download/open books, try a dictionary and enable airplane mode. Local files require no server, VPN or AI. No persistent network daemon, forced Wi-Fi, autostart or mass debloat is part of this setup.
