# Execution gates

| Gate | Evidence before proceeding | Stop condition |
|---|---|---|
| G0 Scope | Offline reading; inspect installed changes and host tools | Redundant/destructive additions |
| G1 Identity | Exact model/firmware, unique storage, current power/space | Guessing, unsupported combination or unstable power |
| G2 Backup | Private visible-data copies, integrity checks and explicit limits | Missing irreplaceable data, unstable DB or insufficient space |
| G3 Approval | Concrete upstream method, artifacts, risks and recovery accepted | USB confirmation mistaken for general write permission |
| G4 Jailbreak if needed | Exact wizard-selected sequence and observed result | Unexpected screen or error; no reset/retry loop |
| G5 Reader | Reviewed matching package, originals retained, real EPUB opens | Wrong architecture or out-of-scope changes |
| G6 Dictionary | Actual popup, priority/language, vocabulary and offline use | Engine-only proof or format mismatch |
| G7 Covers | Amazon and KOReader separately, page/notes on wake | Rerunning a patch that already worked |
| G8 State | Annotation/progress backup and restore rehearsal on copies | Blind overwrite or hidden/cloud assumptions |
| G9 Finish | Airplane-mode reading, normal suspension, honest limits | Forced connectivity or unmeasured speed/battery claims |

On a configured device, start with inspection, not a new exploit.

Unlocking, selecting a jailbreak book, opening a scriptlet, checking cover and confirming a wake location may require physical interaction. Complete PC work first and request one clear action. Copying a file is not execution.

Finish with exact changes/versions/provenance, backup scope, real tests and remaining risks. Separate tool observations, owner screen confirmations and untested claims. Optional servers/network/AI require a new scope; they are not an automatic final step.
