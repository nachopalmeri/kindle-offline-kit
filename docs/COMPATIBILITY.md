# Compatibility gate

Checked2026-10-22. The case is PW6 (Paperwhite12th generation,7-inch) on5.20.1, not every Paperwhite, Basic, Scribe, Colorsoft or Fire tablet.

The [Véra source metadata](https://github.com/KindleModding/kindlemodding.github.io/blob/main/content/jailbreaking/Vera/__index.md) lists PW6 with a5.20.1 limit at this check. The [rendered guide](https://kindlemodding.org/jailbreaking/Vera/) still contains older nearby-version advice referring to5.19.6.

Do not resolve this discrepancy by selecting a neighboring firmware. Use the live official selector/wizard on execution day, record the exact choice/revision and stop if it does not offer the actual combination. Ask upstream support rather than treating a Reddit workaround as compatibility.

Jailbreak enables third-party execution; KPM manages packages; KOReader is the reader. The case had KPM package2026.7.2 but actual KOReader git-rev v2026.07.1. Do not upgrade a working installation to imitate a guide's package number.

Use matching hard-float/kindlehf packages where upstream specifies them. Old soft-float extensions are not interchangeable. Native Amazon dictionaries and KOReader StarDict formats/settings differ.

USB backup is not a full image or unbrick guarantee. Reset is not routine rollback; deregistration can remove Documents content and OTA modifications affect recovery. Read the [reset recovery guide](https://kindlemodding.org/jailbreaking/recovering-from-a-reset.html) before any separately approved recovery action. No flashing/downgrade recipe is included.
