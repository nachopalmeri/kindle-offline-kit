# Diagnose before retrying

- **Only charging/no MTP:** exit KOReader normally; check native library, data cable and host detection. No assumed drive letter or random driver.
- **Uploaded script did nothing:** MTP cannot execute it. Check expected report and required physical library tap.
- **Launcher absent:** inspect the exact package outcome/upstream instructions; no mixed KUAL/soft-float bundles.
- **Cover only in KOReader:** native settings/ad state are separate; see COVERS.md.
- **Dictionary missing in Amazon:** KOReader StarDict and native formats/settings differ.
- **Copied book starts elsewhere:** progress is reader-local; preserve original sidecars and do not promise migration.
- **Optional network client offline:** local reading remains usable. One wake/Wi-Fi/connectivity round, then inspect process/socket/auth state. Stale socket does not mean live daemon; do not disable sleep.
- **Blank screen/boot loop/update failure:** stop and record exact last action; consult upstream recovery/support. No blind reset, flash, deregistration or repeat payload.
- **Battery concern:** compare equivalent lighting/network/indexing usage; pause the last optional feature before adding changes.

Public issues need synthetic text/redacted summaries, never full logs, databases, book inventories or private screenshots.
