# Hilo para X — borrador, no publicado

Cada bloque numerado es un post. Publicarlos como respuestas encadenadas. No adjuntar registros ni capturas privadas del dispositivo.

## 1/6

Conecté mi Kindle por USB y usé un agente de IA para configurarlo para leer mejor.

KOReader, diccionarios offline y portadas, conservando el lector de Amazon.

Dejé el proceso en un repo para que puedas pasárselo a Claude Code o Codex. 🧵

## 2/6

Lo uso en el tren, muchas veces sin Wi-Fi.

Por eso elegí libros y diccionarios guardados en el Kindle, con vocabulario y ajustes de lectura.

La IA ayuda a configurarlo desde la PC. Después podés leer sin conexión.

## 3/6

Para leer en inglés: diccionario inglés sencillo, inglés–español y uno inglés–inglés más amplio.

También EPUB en KOReader y portada al suspender.

Conservé Amazon para seguir usando sus libros. Cada lector mantiene su propio progreso.

## 4/6

→ Identificar modelo y firmware.
→ Respaldar antes de tocar nada.
→ Verificar compatibilidad en fuentes oficiales.
→ Pedir aprobación del plan.
→ Probar lectura, diccionarios y suspensión.
