# Privacy and safety

No guarantee of firmware recovery or zero risk. Matching hashes do not certify full backup coverage.

Do not post serials, accounts, IPs, credentials, login links, Tailscale state, screenshots with private content, databases, books or raw logs. Use a redacted/synthetic reproduction.

For security concerns use GitHub private vulnerability reporting if available, or an existing private contact channel. Do not disclose private data in a public issue merely because private reporting is unavailable.

This repo has a local comparison helper and documentation, not a device-writing installer, telemetry or remote access service. Linked dependencies have their own security models.
